# 🌍 IP Address Tracker

A modern IP Address Tracker web application that allows users to search for any IP address or domain and instantly view its geographical location, Internet Service Provider (ISP), timezone, and location on an interactive map.

🌐 **Live Demo:** https://ip-bice-rho.vercel.app/

---

## ✨ Features

- 🌍 Search any IPv4 or IPv6 address
- 🔎 Search using a domain name
- 📍 Display accurate geolocation
- 🗺️ Interactive map with location marker
- 🏢 View Internet Service Provider (ISP)
- 🕒 Display timezone information
- 📱 Fully Responsive Design
- ⚡ Fast and User-Friendly Interface

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/yourusername/IP-Address-Tracker.git
```

### Navigate to the Project

```bash
cd IP-Address-Tracker
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

---

## 📸 How It Works

1. Enter an IP address or domain name.
2. Click the search button.
3. The application fetches the IP details.
4. View:
   - 📍 Location
   - 🏢 ISP
   - 🕒 Timezone
   - 🗺️ Interactive Map
